# Loopa

Protótipo front-end de um aplicativo para organizar projetos de crochê, tricô e outras criações manuais.

## Telas

- `index.html` — boas-vindas
- `login.html` — acesso ao aplicativo
- `projetos.html` — lista de projetos, criação de projeto e contador de carreiras

## Como executar

Abra o arquivo `index.html` em um navegador. Não há dependências, servidor ou processo de compilação: o projeto usa apenas HTML, CSS e JavaScript.

## Estrutura

```
loopa-inicio/
├── index.html / styles.css / app.js
├── login.html / login.css / login.js
├── projetos.html / projetos.css / projetos.js
└── logomarca-loopa.png
```

## Funcionalidades do protótipo

- Navegação entre boas-vindas, login e ateliê
- Criação de projetos com nome, meta e cor
- Contador de carreiras e indicador de progresso
- Área de receita e lista de materiais
- Feedback visual de salvamento local
